# Search Cases

## Expected relevant source

- Which mission was the first crewed Apollo flight in Earth orbit?
- Which crewed mission travelled around the Moon before anyone landed there?
- What happened during the 1967 preflight test?
- Which mission brought its crew home after an explosion stopped the planned landing?
- Which mission first drove a vehicle on the Moon?
- When did the final Apollo lunar mission splash down?

## Expected abstention

- How do I reset the password for my online banking account?
- Which Apollo mission landed astronauts on Mars?

The second abstention is deliberately difficult. It shares the words “Apollo”,
“mission”, “landed”, and “astronauts” with the corpus even though the requested
event never happened. Use it to discuss why similarity alone does not prove that
a passage supports a claim.

## Metadata filter cases

- Search for the mission that used a vehicle, restricted to lunar landings from 1970 onwards.
- Search for the first crewed flight, restricted to `earth_orbit`.
- Search for the final mission, restricted to missions from 1972 onwards.
- Apply `lunar_orbit` and a minimum year of 1970. The filters should return no result.
