# Session 3 — Embeddings and Semantic Search

Material for the third session. The exercises use the prepared passages from
the Knowledge Copilot mini-project.

## Run an example

```bash
uv run python sessions/03-embeddings-semantic-search/starter/01_embed_passages.py
```

The second exercise is a guided implementation challenge:

```bash
uv run python sessions/03-embeddings-semantic-search/starter/02_semantic_search.py
```

## Structure

```text
starter/   # Runnable example and guided exercise
test-data/ # Manual search cases
```
